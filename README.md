# Saksham Rai --- Cloud & DevOps Portfolio

A premium, animated portfolio for a Cloud & DevOps Engineer, built as a
clean cloud infrastructure experience.

**Stack:** React · Vite · Framer Motion · Lucide React · React Icons ·
CSS

    mobile screens.

## Featured Projects

### Full DevOps Automation Platform

A complete AWS deployment platform that automates infrastructure
provisioning, container builds, and application deployment through a
CI/CD workflow.

**Technologies:** AWS · Terraform · Docker · GitHub Actions · ECR · IAM

-   Architected and containerized 10+ backend applications and REST
    endpoints
-   Provisioned AWS EC2 infrastructure using Terraform
-   Automated container builds and deployments using GitHub Actions
-   Reduced manual deployment time by 75%
-   Implemented IAM-based access control and GitHub Secrets
-   Followed least-privilege practices with no hardcoded credentials

[View Source](https://github.com/Raisaksham4/devops-project)

### AWS Cost Optimization & Governance Tool

A Python-based AWS resource scanner that identifies orphaned and
underutilized infrastructure, generates reports, and supports safe
dry-run remediation.

**Technologies:** Python · Boto3 · Terraform · LocalStack · AWS

-   Scans orphaned EBS volumes
-   Detects stopped EC2 instances
-   Identifies unassociated Elastic IPs
-   Detects untagged AWS resources
-   Supports safe dry-run remediation
-   Generates JSON and Markdown reports

[View Source](https://github.com/Raisaksham4/AWS-Cost-Optimization)
